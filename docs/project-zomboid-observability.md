# Project Zomboid native telemetry contract (Habiki)

Validated against the installed Build 42 server on 2026-09-24 after a targeted Habiki NixOS deploy. The game starts its native HTTP exporter with `-DprometheusPort=9105`; `GET http://127.0.0.1:9105/metrics` returned HTTP 200 with 43 metric names. The embedded exporter binds `*:9105` and has no verified bind-address setting. Declarative IPv4 and IPv6 `nixos-fw` REJECT rules deny TCP 9105 arriving on non-loopback interfaces. A request from Bullit to Habiki's LAN address failed; a Habiki loopback request succeeded. Do not remove these firewall guards or allow TCP 9105 through another path. The scrape payload includes server identity; restrict access to operators.

The observed signal names and label keys (no player identities or coordinates are recorded here):

| Signal | Verified native selector | Semantics |
| --- | --- | --- |
| Online player count | `game{parameter="players"}` | Current connected players; zero was observed during the test. |
| Server FPS | `performance{parameter="fps"}` | Native server performance FPS, **not client rendering FPS**. |
| Zombies | `game{parameter="zombies-loaded"}`, `game{parameter="zombies-simulated"}`, `game{parameter="zombies-total"}` | Distinct loaded, simulated, and total counters; do not merge. |
| Animals | `game{parameter="animals-instances"}`, `game{parameter="animals-objects"}` | Current animal instances versus objects; no animals were observed during the test. |
| Cells | `game{parameter="loaded-cells"}` | Loaded world cells, not all cells in the world. |
| Daily events | `connection{parameter="zombies-killed-today"}`, `connection{parameter="burned-corpses-today"}`, `connection{parameter="players-killed-by-zombie-today"}` | Game's current-day event totals; the dashboard applies `increase(...[1h])` for approximate rolling-hour counts and accounts for game-day resets. |
| JVM heap | `jvm_memory_used_bytes{area="heap"}` | JVM heap bytes; nonheap has `area="nonheap"`. |
| Process CPU | `rate(process_cpu_seconds_total[5m])` | JVM process CPU seconds per second; can exceed one on multiple cores. |
| Process resident memory | `process_resident_memory_bytes` | JVM resident set bytes. |
| Network | `network{parameter="received-bps"}`, `network{parameter="sent-bps"}` | Game's sampled receive/send bytes per second. |
| Runtime | `process_start_time_seconds`, `jvm_threads_current`, `jvm_gc_collection_seconds_count`, `jvm_gc_collection_seconds_sum` | Process start, threads, and JVM GC activity. |
| Server identity | `pz_info` | `ServerName`, `UDPPort`, `checksum`, `gamePort`, `ip`, `version` labels; not a reliable game-port reachability probe. |

The native `game`, `connection`, `performance`, `network`, and `pool` series use a `parameter` label. A subsequent controlled online-player test captured `player_x`, `player_y`, `player_lat`, and `player_lon`, each with `id` and `name` labels, while `game{parameter="players"}` reported one player. Latitude/longitude values were finite but **do not align with the installed game map's world X/Y projection**; never plot them against a geographic basemap. No player identifiers or positions are stored in this document. These live series are absent when nobody is online; the roster uses `player_x` grouped by `name`, and the selected-player map uses `player_x`/`player_y` matched by `name` and projected onto private Build 42 game-map tiles. `performance{parameter="fps"}` is available, while a distinct tick-rate signal has not been identified; show a separate tick-rate request as unavailable.

Habiki includes `media/maps/Muldraugh, KY/worldmap.png` at 10234×8314 pixels. Its in-game map raster is 2 game tiles per pixel with a 125-image-pixel inset; the playable world is 19968×16128 game tiles. Declarative NixOS generation removes the inset and serves the resulting XYZ tiles beneath the existing `/grafana/` HTTPS prefix, protected by Grafana's own session check. To align Geomap's mandatory Web Mercator coordinate system, place game coordinate (0,0) at the map's equator and project `lon = player_x / 111319.4908`, `lat ≈ -player_y / 111319.4908` (approximation error < 0.02 game tiles across the world). Do not use native `player_lat`/`player_lon` here: the controlled-player values did not align with this map projection. No game artwork is checked into git. `project-zomboid-map-tiles.service` regenerates the authenticated static tile cache at `/var/lib/project-zomboid-map/tiles` when the installed PNG hash changes; inspect its journal if the map is blank. The tile URL is `/grafana/project-zomboid-map/{z}/{x}/{y}.webp`. An anonymous request returns HTTP 401; the same tile returns HTTP 200 `image/webp` with a valid Grafana identity. Putting the tile route under `/grafana/` ensures browsers send their Grafana session cookies; Caddy checks `/grafana/api/org`, which recognizes human sessions and renderer service accounts (unlike `/api/user`, which returns 404 for the renderer identity). The earlier separate Authentik route returned HTTP 302 even with a valid Grafana token, so was removed. No publicly reachable TCP listener is created. The vault-token-protected Grafana image renderer listens only on `127.0.0.1:18081` (Dependency Track owns loopback port 8081), with one concurrent render. Its callback uses `https://metrics.net.scetrov.live/grafana/` so the Chromium browser fetches authenticated map tiles through Caddy; a localhost Grafana callback bypasses the tile route and shows a blank backdrop. `gcx dashboards snapshot svc-project-zomboid --panel 22` produces a game-map image with player markers. The dashboard keeps a compact player selector because built-in Geomap legends cannot dynamically name and toggle each player. Its half-width map has a near-native aspect ratio and uses a fixed world-centered viewport; player paths outside that viewport require zoom or pan. The roster displays Unavailable when no player is online instead of a redundant location-coverage panel.

After the player joined, a focused Loki query `{service="project-zomboid",host="habiki"}` returned a stream with `unit="project-zomboid.service"`, confirming the Alloy journal relabel and host correlation. Older logs from before the relabel may lack the `service` label. Process CPU and RSS are JVM-attributable, so no host-wide proxy or additional collector is needed.

The validation kept RCON disabled (the module's profile initialization sets `RCONPort=0`, `RCONPassword=`), installed no client software and did not introduce a RCON credential. The endpoint is enabled through NixOS automation, not an imperative edit to mutable game state.
