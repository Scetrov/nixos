## Approved Isolation Exception

The operator explicitly approved the rootless Podman fixture outside Bubblewrap. The fixture uses the repository's digest-pinned Caddy image, Podman's default container network, a single random `127.0.0.1` published port, and one read-only mount from a temporary `hermes-auth-*` directory to `/etc/caddy/Caddyfile`. No credentials or host sockets are mounted into the container. Container and temporary configuration are removed on completion. Residual risk: the host-side test process can control the operator's rootless Podman runtime, and the default container network is not egress-isolated. Other local tests run with Bubblewrap's isolated network and project-only write scope.
